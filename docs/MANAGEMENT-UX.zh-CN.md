# 深层管理交互改造（2026-10-24）

## 交互规则

- 全局设置按常用、模型与资料、能力与自动化、团队、系统与扩展分类，支持名称与关键词搜索。高级入口可展开/收起，保留原有角色访问限制。
- 资料库设置分为基本信息、回答方式、资料检索、自动执行、成员权限。技术参数放在可展开区域，说明只影响当前资料库还是影响全局。
- 自动保存明确显示状态。保存失败保留输入、提供重试；串行保存防止较早响应覆盖最新修改。资料库设置以及资料理解、索引存储、分段设置有未保存离开保护。
- 资料管理按已加入、添加、其他来源导入组织。上传后勾选并直接加入，不再先移动到另一列再二次保存。移出资料库与永久删除原始文件分开说明。
- 文件搜索清除旧选择，搜索结果中的文件夹勾选只作用于匹配项。显示已选数量并允许取消选择。失败时清理错误的排队状态。
- 删除资料库需要输入名称确认。危险设置说明实际影响，确认弹窗优先聚焦取消，提交期间禁止重复操作。

## 本轮验收

- 实际浏览器验证资料库名称、开场问题、回答模式保存。
- 模拟保存失败，确认输入保留、重试成功以及离开页面保护。
- 对第一次保存增加延迟，连续修改名称，确认服务端与界面均保留最后一次输入。
- 临时文本文件实际上传、加入临时资料库、移出；模拟加入/移出失败并成功重试。
- 检查搜索选择请求只包含临时文件，永久删除确认显示正确数量；删除临时资料库前名称为空时无法提交。临时资料与资料库已清理。
- 全局分段设置使用拦截请求验证失败保留与离开保护，没有改动真实全局配置。
- 检查资料理解、索引存储、语音、安全入口与搜索。检查390像素宽度的资料库设置、资料管理、来源导入、全局分段设置，无横向溢出。
- 前端ESLint、生产构建和12项Node回归测试通过，本地三项服务健康。

## 验证范围

没有逐一连接所有第三方资料来源，也没有开启多用户模式去创建团队账号；这些服务特定配置和权限组合仍沿用原版实现。没有更改现有MiMo密钥或用户资料。
