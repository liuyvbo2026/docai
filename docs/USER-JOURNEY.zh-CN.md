# 普通用户完整流程验收 · 2026-10-24

## 本轮调整

- 首页显示当前使用的资料库，直接提供“管理长期资料”。“上传文件提问”明确只供当前对话参考。
- 新建资料库拒绝纯空格名称，创建失败保留名称；提交时不重复创建。
- 对话字号和导出格式改为点击可用，不依赖鼠标悬停。菜单支持 Escape 和焦点返回；复制对话地址说明本机链接的限制，失败时可手动复制。
- 连续上传追加到同一队列，失败文件保留并可逐个重试。上传过程中禁止提前关闭资料管理、提前加入仍在上传的文件。
- 全局回答要求直接编辑，说明只影响之后新建的资料库。手动保存、恢复默认、失败保留、未保存离开保护使用一致反馈。
- 常用信息的添加、编辑、删除改为中文表单和明确确认；系统动态内容不再显示为空白。
- 工具页支持窄屏列表与独立详情，修复导航区域遮挡点击。保存栏置于底部，不遮住返回；保存失败保留修改，“放弃修改”恢复实际设置；离开前提示未保存。
- 工具空状态、状态标签、运行记录详情和清空提示改为更清楚的文字，保留原有权限限制和服务能力。
